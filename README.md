# Food Delivery Data Analysis
This notebook contains the complete workflow for loading, merging, and saving for analysis food delivery data from CSV, JSON, and SQL sources using Python and Pandas. By analysing the merged file we can answer key questions related to revenue, user behavior, and performance across cities and cuisines.
## Technologies used:
- Python
- Pandas
- SQLite
- Jupyter Notebook
## Key Steps
- Loaded data from CSV, JSON, and SQL files
- Merged datasets using left joins
- Cleaned and prepared the final dataset
- Answered analytical questions
